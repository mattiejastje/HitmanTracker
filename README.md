# HitmanTracker

A statistics tracker for Hitman games.

## Supported Games

### Hitman: Codename 47

Game detected, but currently no stats are tracked.
Note the game has no rating system of its own.

### Hitman 2: Silent Assassin

Nearly fully supported. Known issues:

* Difficulty is not yet tracked.
* Shots fired pointer is experimental.

### Hitman: Contracts

Nearly fully supported. Known issues:

* Difficulty is not yet tracked.

### Hitman: Blood Money

Fully supported.
